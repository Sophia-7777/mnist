# MNIST MLP

A simple Multilayer Perceptron (MLP) for MNIST handwritten digit classification.

## 📁 Project Structure

```text
mnist/
├── data/
├── 1.png
├── 2.png
├── mnist_mlp.pth
├── predict_mnist.py
├── train_mnist.py
└── README.md
```

## 🛠️ Requirements

- Python 3
- PyTorch
- torchvision
- Pillow

## 🚀 Training

```bash
python train_mnist.py
```

## 🔍 Prediction

```bash
python predict_mnist.py
```
